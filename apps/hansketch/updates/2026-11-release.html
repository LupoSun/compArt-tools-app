01

Palette colours for Relief Shadow

Earlier release

Load a palette in Shape Settings, then choose its swatches under Relief Shadow → Colour. The shadow can use the artwork’s palette; shadow Opacity controls how it blends with the paper.

Relief Shadow → Colour · palette swatches

02

Select all or build a selection

Earlier release

Cmd/Ctrl+A selects visible, unlocked forms. Use Shift-click to add or remove forms one at a time. Move, scale, rotate, duplicate or delete the group; Undo reverses the complete operation.

Select (V) · Shift-click · Cmd/Ctrl+A

03

TIFF & vector PDF export

Earlier release

TIFF exports lossless RGB at the selected print resolution, with DPI metadata. Artwork PDF keeps vector contours and the physical paper size; soft shadows are images at print resolution.

Export → TIFF / PDF · artwork

04

Reset settings, keep the artwork

Earlier release

Edit → Reset Settings restores physics, drawing and appearance defaults. The artwork, layers, palette and paper size stay in place. Cmd/Ctrl+Z restores the previous settings.

Edit → Reset Settings

05

A3 by default, A2 included

Earlier release

New sketches start at A3 portrait, 300 dpi: 3508 × 4961 px. A2 adds 4961 × 7016 px. Both orientations are available. Existing sketches keep their size; zoom changes only the view.

Appearance → Canvas Size

06

Every layer for screen printing

Earlier release

Export one black-on-white PDF page per layer, including hidden and locked layers. Page size and alignment match. Shadows and ground are omitted; tonal opacity may need halftoning by the printer.

Export → PDF · all layers for screen printing

07

Record the living artwork

New in this release

Record artwork without editor guides. Choose duration, target frame rate and image size; save MP4 or WebM where supported. Filmstrip is visible. MOV needs conversion; timing depends on the device.

Export → Record animation… / Filmstrip

08

Choose colour opacity

New in this release

Set opacity for new or selected forms: fully opaque, semi-transparent or transparent. Overlapping forms blend as washes. Freeze preserves the chosen opacity; zero opacity keeps the form’s geometry.

Form properties → Opacity · 100% / 50% / 0%

09

Make pigment stains

New in this release

Add twelve irregular, translucent forms from a seed. The loaded palette supplies their colours. They start frozen and can be moved or recoloured. Reuse a seed for the same pattern; each stain remains editable.

Nature Lab → Pigment stains · Seed

10

Zoom in, keep the paper size

New in this release

Zoom with the wheel or + / −. Pan to move around; use two-finger pinch in Pan mode. Fit brings the whole sheet back. Paper dimensions, export resolution and physics stay unchanged.

Canvas view controls → Zoom · Pan · Fit

11

Give the shadow more space

New in this release

Spread enlarges the shadow’s silhouette. Distance moves it; Softness softens its edge. Larger ranges allow broader relief effects. The artwork exports include these shadow settings.

Relief Shadow → Distance · Softness · Spread

12

Set gravity, direction & wind

New in this release

Environment exposes gravity on/off, direction and wind. Adjust gravity strength with its physics dial. Settings use relative studio units and a directional field, with explanations in the handbook.

Environment + physics bar → Gravity strength

MOV needs external conversion. Recording support and timing depend on the browser/device.

13

Different falling, form by form

New in this release

Select forms to set relative mass, air resistance and artistic gravity influence. Without air, mass alone does not change falling acceleration. With drag, light and heavy forms can fall differently.

Form properties → Mass · Air resistance · Gravity influence

14

Research feasible nature methods

Research completed

Compared falling, elasticity, contour growth and rule-based branching, with source links and limits. Space colonization and Gray–Scott remain researched future directions, not active simulation modes.

Research comparison + Handbook → Nature & sources

15

Growing contours & branching

Experimental models

Try bounded 2D contour growth and seeded branches. Growth has page, point and step limits; forms with holes are excluded. Branches are separate paths. These simplified models do not simulate biology.

Nature Lab → Differential contour growth / Branching rules

16

Teach phenomena in the interface

New in this release

Falling and elasticity studies pair a phenomenon with an explanation and Add study layer. These are simplified models. Studies change global physics; Undo removes the layer and restores prior settings.

Nature Lab → Explanation · Add study layer · Undo

17

A small shared handbook

New in this release

German reference for controls, meanings and examples: materials, gravity, growth, export and shortcuts. Exercises, sources and troubleshooting are included. Open it from the title bar, Help or Nature Lab; print it.

Handbook · Help → Handbook · Nature Lab

18

JPG / PDF: keep the whole shadow

Fixed in this release

The crescent is reproduced when browser blur is ignored. JPG/PDF now reuse canvas shadows; inward edge shadows are fixed too. All 16 comparisons pass. Synthetic reproduction; original scene not replayed.

JPG / artwork PDF · A3 / 300 dpi · shadow repair included

Nature Lab uses simplified artistic models. JPG/PDF shadow repair verified at A3 / 300 dpi.
